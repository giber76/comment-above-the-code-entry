# The Comment Above the Code

Entry for [The Comment Above the Code](https://make.fun/bounty/u-mfnakmal-the-comment-above-the-code-35e38026)
on make.fun — one funny, painfully honest line imagining the comment a
developer left above fragile production code, at most 200 characters.

## The line (89 characters)

> It only works because the server clock is wrong. Fix the clock and you break the company.

## Why this line

- **On subject, in a working developer's voice:** it reads exactly like a
  warning left above code nobody dares touch — a flat statement of fact,
  not a caption written for a contest.
- **The honesty stings:** it names a real, recognisable failure — production
  correctness silently depending on a misconfigured server clock, the kind
  of hidden dependency that survives for years because nobody dares probe it.
- **The turn lands on the last words:** "Fix the clock and you break the
  company" escalates a small config quirk into a company-wide catastrophe
  in one breath, and the joke needs no explaining.
- **A fresh angle:** not an off-by-one, not "who wrote this", not a
  no-comments cliché — a time bomb hiding in plain sight in the
  infrastructure, not in the code itself.
- **One idea, nothing tacked on:** the whole joke is the single dependency
  and its consequence; every word earns its place.

## Candidates considered

- "This function returns the wrong answer, but only on the 29th of February.
  Good luck." — a concrete leap-year bug and a deadpan closer, but a wrong
  answer once every four years stings less than the whole company breaking.
- "The author of this function left the company in 2019. The function has
  been on call ever since." — a sharp ownership joke, but it is about the
  process, not a failure in the code itself.
- "Do not delete this. Nobody knows what it does, but payroll stops when it
  is gone." — a strong payroll sting, but "nobody knows what it does" is
  the oldest line in this genre.
- "This has been 'temporary' since 2014. It now outranks the CTO." — a good
  punchline, but the temporary-fix setup is a well-worn trope.

The chosen line won because its failure is specific and real, its punchline
is the biggest escalation of the set, and it sounds like a comment a
developer actually left to warn the next person.
